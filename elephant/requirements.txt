# Deps for the elephant face-recognition demo (target board). Like dolphin: NO pip installs.
#
# The board's system python3 is 3.13, and the BSP ships everything this pilot needs:
#   gi (GStreamer/Wayland), tflite_runtime (ABI-matched to the neutron delegate), numpy, and
#   cv2 - whose bundled FaceDetectorYN (YuNet) + FaceRecognizerSF (SFace) ARE the face models here.
# Create the venv so it can see them:
#     python3 -m venv --system-site-packages ~/elephant/venv
#
# The two face ONNX files are data, not pip packages - fetch on the host with
# scripts/face-models-fetch.sh and deploy.sh copies them next to the code.
#
# Requires OpenCV >= 4.5.4 in the BSP for the face classes. Verify on-device first:
#     python3 diag-face.py face_detection_yunet_2023mar.onnx face_recognition_sface_2021dec.onnx
